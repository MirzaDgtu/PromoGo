# Q: Расскажи про наш проект для инвесторов. Попробуй донести цель данного проекта. Постарайся сделать это кратко. Расскажи что сделано, что планируется в будущем

## Answer

Expanded from original query via graph vocab: [promo, product, current, implementation, scope, planned, architecture, roadmap, phase, mechanics, loyalty, multistore]; implemented-scope query: [api, points, accrual, redemption, refund, registration, identity, notifications, administrative, webhook, idempotency, docker]. PromoGo — независимая backend-платформа лояльности для ритейла: она подключается к 1С/POS, ведёт балансы и историю операций и даёт API клиентским и административным приложениям. Цель — позволить ритейлерам запускать и развивать программы лояльности без замены учётной системы, а затем повышать удержание и повторные продажи через аналитику и маркетинг. Уже готово ядро backend на Go: начисление и списание баллов, настраиваемые правила, ledger и идемпотентность, API 1С/POS, OTP-сессии клиентов, OIDC/RBAC сотрудников, управление организациями, магазинами и API-ключами, аудит, PostgreSQL/Redis, миграции, OpenAPI, тесты и Docker Compose. Мобильное приложение и web-конфигуратор пока описаны в продуктовых документах, но не входят в текущий код; SMS/push-провайдеры ещё не подключены. Далее: завершить пилот с 1С, мобильным приложением и минимальным web-конфигуратором; затем добавить мультимагазинность, новые механики, возвраты и усиленный антифрод; после этого — аналитику/RFM, кампании, рефералы и геймификацию; в зрелой фазе — SaaS multi-tenancy, биллинг, self-service и интеграции с другими ERP/POS.
