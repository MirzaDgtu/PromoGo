# Q: Есть ли на данный момент регистрация и авторизация? Роли пользователей?

## Answer

Expanded from original query via graph vocab: [registration, identity, client, customer, api, key, store, security, administrative]. Частично: техническая регистрация клиента существует — POST /api/v1/transactions от авторизованного магазина/1С автоматически создаёт Client по неизвестному телефону. Это не пользовательская регистрация: отдельного register/login, OTP, согласия, пароля, JWT или session/refresh token нет. Авторизация реализована только для магазина/1С через Authorization: Bearer <store-api-key>; middleware хеширует ключ SHA-256, находит Store и ограничивает запрос контекстом магазина. Клиентской и административной авторизации нет. RBAC и роли не реализованы: отсутствуют User/Role/Permission модели и таблицы; store API key является store scope, а не ролью. В документах запланированы retailer и platform admin, а backlog рассматривает owner, store admin, marketer, support, read-only и platform admin, но решение ещё не принято.
