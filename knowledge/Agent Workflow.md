# Работа Codex и Claude Code через Graphify

## Перед работой

1. Если `graphify-out/graph.json` существует, сначала выполнить узкий запрос:
   `graphify query "<вопрос>"`.
2. Для связи двух сущностей использовать `graphify path "<A>" "<B>"`.
3. Для одной сущности использовать `graphify explain "<сущность>"`.
4. Читать исходные файлы, на которые ссылается результат, и проверять
   `INFERRED`/`AMBIGUOUS` связи по коду перед изменением.
5. Сверять открытые продуктовые решения с [[Project Questions]], а принятые —
   с [[Decisions]].

Если исполняемый файл не находится в `PATH`, все команды запускаются как
`python -m graphify ...`.

## После работы

1. Выполнить тесты, относящиеся к изменению.
2. Выполнить `graphify update .`.
3. Если принято решение, перенести вопрос в [[Decisions]] и отметить исходный
   пункт ссылкой на решение.
4. Если ответ Graphify оказался полезным, тупиковым или исправленным, сохранить
   результат через `graphify save-result`, чтобы накопленная память влияла на
   следующие запросы.

## Разделение ответственности

- Codex и Claude используют один и тот же `graphify-out/graph.json`.
- `AGENTS.md` задаёт постоянные правила для Codex.
- `CLAUDE.md`, `.claude/CLAUDE.md` и hooks задают правила для Claude Code.
- `.mcp.json` предоставляет Claude Code нативные MCP-инструменты Graphify.
- Любое утверждение агента о связи компонентов должно иметь путь в графе или
  прямую ссылку на исходный файл.
